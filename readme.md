# Viredian – Marketing Landing Page

Viredian is a modern, fully responsive marketing landing page converted from Figma into clean, production-ready code. It is designed with a strong focus on conversion, performance, and user experience, delivering a premium digital interface for showcasing a product or SaaS solution.

The website is built using HTML, CSS, JavaScript, and jQuery, ensuring smooth interactions across all devices. It includes engaging animations using Owl Carousel and AOS (Animate On Scroll), creating a dynamic and modern browsing experience. The layout is carefully structured with a clear hero section, feature highlights, dashboard showcase, and strong call-to-action sections.
